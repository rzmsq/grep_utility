# grep_utility

Консольная утилита для поиска строк по шаблону в файле или потоке ввода, аналогичная команде grep.

## Сборка

```
make
```
или
```
go build -o grep_utility ./cmd
```

## Запуск

```
./grep_utility [флаги] <pattern>
```

- Если не указан флаг `-f`, чтение происходит из STDIN.

## Примеры

```
./grep_utility -i -A 2 -f test.txt error
```

## Поддерживаемые флаги

- `-A N` — вывести N строк после совпадения
- `-B N` — вывести N строк до совпадения
- `-C N` — вывести N строк вокруг совпадения
- `-c` — вывести только количество совпадений
- `-i` — игнорировать регистр
- `-v` — инвертировать совпадения
- `-F` — искать фиксированное совпадение (без регулярных выражений)
- `-n` — выводить номера строк
- `-f <file>` — путь к файлу для поиска
